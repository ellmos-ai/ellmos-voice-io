# Code of Conduct / Verhaltenskodex

## Our pledge / Unser Versprechen

We want participation to be respectful, inclusive, and focused on safe,
reproducible local-first software. Harassment, discrimination, threats, and
publication of another person's private data are not acceptable.

Wir möchten eine respektvolle, inklusive und auf sichere, reproduzierbare
Local-First-Software ausgerichtete Zusammenarbeit. Belästigung,
Diskriminierung, Drohungen und die Veröffentlichung privater Daten anderer
Personen werden nicht akzeptiert.

## Expected behavior / Erwartetes Verhalten

- Discuss evidence and technical trade-offs, not personal characteristics.
- Respect consent, microphone, recording, credential, and release boundaries.
- Never attach private recordings or transcripts to public issues.
- Report security and privacy failures through a private channel.

- Diskutiere Belege und technische Abwägungen statt persönlicher Eigenschaften.
- Respektiere Einwilligungs-, Mikrofon-, Aufnahme-, Zugangs- und Freigabegrenzen.
- Hänge privaten Issues niemals Aufnahmen oder Transkripte an.
- Melde Sicherheits- und Datenschutzfehler über einen privaten Kanal.

## Enforcement / Durchsetzung

Maintainers may edit or remove contributions that violate this code and may
restrict participation when necessary. Use GitHub Security Advisories for
reports containing security or personal information.

Maintainer dürfen Beiträge bearbeiten oder entfernen, die gegen diesen Kodex
verstoßen, und die Mitwirkung bei Bedarf einschränken. Nutze GitHub Security
Advisories für Meldungen mit Sicherheits- oder Personendaten.
